Run the DogecoinVM proxy

        
The wallet pages are static. A browser cannot call metaldoge.com directly, because that site does not allow it. The program in the metaldoge folder forwards only public lookups and signed payments. Keys never go through it.

        
    
          
  1. 1Install Node 18 or newer. There are no packages to install.
    2. 
          
  2. 2On the server, open the metaldoge folder and start the proxy. It listens on 127.0.0.1, port 8787.
    3. 
          
  3. 3Put HTTPS in front of it. nginx can pass visits to 127.0.0.1:8787.
    4. 
          
  4. 4Set TRUST_PROXY=1 when nginx is the only program that can reach that port, so each visitor is counted on their own.
    5. 
          
  5. 5Set ALLOWED_ORIGINS to your website address. The proxy answers only those sites.
    6. 
        

        
cd metaldoge
node server.mjs

        
On Windows, set TRUST_PROXY=1 in the terminal, then run node server.mjs.

        
ALLOWED_ORIGINS=https://example.com TRUST_PROXY=1 node server.mjs

        
It forwards only chain info, an address lookup, a transaction lookup, and a signed payment. Every other path is refused.

        
In the wallet Settings, choose Custom for DogecoinVM and enter the https address of your proxy.
